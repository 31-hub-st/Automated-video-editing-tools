# StoryForge 员工电脑快速开始

适用版本：`0.4.4`

## 第一次安装

1. 把管理员提供的**完整 ZIP** 解压到 `D:\StoryForge`，再从该目录运行 `StoryForge Studio.exe`。
2. 目录必须只含英文/ASCII 字符，位于本机固定磁盘且当前用户可写。不要放到中文路径、`Program Files`、OneDrive/网盘、网络共享或 U 盘，也不要只复制 EXE。
3. 输入员工账号和密码。软件会自动读取电脑名称、连接预置 Hub、登记电脑并启用本机制作服务；无需填写 Hub 地址、令牌或运行脚本。
4. 登录成功后可使用桌面端，也可在当前电脑浏览器打开团队网页；两端使用同一套功能。完整桌面窗口可以关闭，本机制作服务会继续处理已排队任务。
5. 在制作台选择这台电脑自己的视频素材、背景音乐和输出文件夹。这些文件不上传 Hub，管理员也不需要替员工指定路径。

程序首次运行会创建 `D:\StoryForge\StoryForgeData`。设置、账号与连接状态、本机数据库、日志、更新状态、渲染工作区、缓存、WebView 数据和临时文件全部保存在这里。

## 从 0.4.2 升级

0.4.2 不能自动更新到 0.4.3 或更高版本。请等待旧任务结束并完全退出旧程序，使用管理员提供的**完整 0.4.4 包**安装到新的 `D:\StoryForge`，再首次启动。

- 不要点击旧版自动更新，也不要把新文件混进旧程序目录。
- 0.4.4 会把旧 C 盘中的长期数据安全复制到 `StoryForgeData`；新目录已有文件不会被旧文件覆盖。
- 如果提示旧本机制作服务仍在运行，先关闭旧版 StoryForge/Worker，再重新打开 0.4.4。
- 完成一次真实 MP4 + MP3 任务并让管理员确认后，才能归档或清理旧 C 盘数据。

## 日常制作

1. 选择小说、平台、口令、发布账号和要合并的分集。
2. 选择生产方案；需要时调整女声、语速、音乐、字幕、开头与封面结尾。
3. 选择“常规视频生成”“仅生成配音”或“已有配音更换素材”。仅生成配音每批只输出一份 MP3；换素材应选择 StoryForge 输出且带内嵌字幕索引的 MP3。
4. 提交批次后可立即配置下一批，队列会按顺序制作；无需等待上一批结束。
5. 一个批次在任务胶片带中显示为一张可折叠卡；结束后可整批归档。

## 员工可用设置

- “制作默认值”用于预览、调整并保存自己的字幕、简介卡、搜索口令和封面结尾方案，不会覆盖团队默认。
- “本机维护与软件更新”用于检查当前电脑的 FFmpeg、H.264 编码器、Kokoro、Edge TTS，并更新当前这台电脑。
- 员工可套用共享方案、覆盖本批参数，且只能修改或删除自己创建的方案。

## 更新、日志与故障

- 0.4.4 后续更新会在空闲时下载到 `D:\StoryForge\StoryForgeData\updates`，并在安全重启时安装。更新包不会覆盖 `StoryForgeData`。
- 启动与运行日志：`D:\StoryForge\StoryForgeData\logs`。
- 单任务错误：`D:\StoryForge\StoryForgeData\render-work\<批次>\<任务>\job-error.log` 或 `render-error.log`。
- 网页能打开但不能试听或生成时，先重新打开一次 `StoryForge Studio.exe` 并登录，再刷新网页。
- 仍有问题时双击 `admin-tools\diagnose_storyforge.cmd`，把诊断结果和对应任务日志交给管理员。`enable_storyforge_worker.cmd` 只供管理员维修，不属于首次使用流程。

## 清理或卸载

先退出 StoryForge 和本机制作服务，再删除整个 `D:\StoryForge` 即可移除 0.4.4 程序及运行数据。员工另行选择的视频素材、音乐和最终输出目录不会被删除。

从 0.4.2 迁移的旧 C 盘目录应先保留作回滚与诊断；只有管理员确认 0.4.3 已完成真实任务后，才可单独归档或删除旧数据。
