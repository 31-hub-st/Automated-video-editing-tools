# StoryForge 员工电脑快速开始

适用版本：`v1.0.5`

## 第一次安装

1. 把管理员提供的**完整 ZIP** 解压到本机固定磁盘，例如 `D:\StoryForge`，再从该目录运行 `StoryForge Studio.exe`。
2. 目录必须只含英文/ASCII 字符，位于本机固定磁盘且当前用户可写。不要放到中文路径、`Program Files`、OneDrive/网盘、网络共享或 U 盘，也不要只复制 EXE。
3. 输入员工账号和密码。软件会自动读取电脑名称、连接预置 Hub、登记电脑并启用本机制作服务；无需填写 Hub 地址、令牌或运行脚本。
4. 登录成功后可使用桌面端，也可在当前电脑浏览器打开团队网页；两端使用同一套功能。完整桌面窗口可以关闭，本机制作服务会继续处理已排队任务。
5. 首次启动选择这台电脑的 `StoryForgeData` 数据目录；再在制作台选择本机视频素材、背景音乐和输出文件夹。视频素材只递归扫描员工所选文件夹，不按小说题材自动换目录。这些文件不上传 Hub，管理员也不需要替员工指定路径。

设置、账号与连接状态、本机数据库、日志、更新状态、语言组件、渲染工作区、缓存、WebView 数据和临时文件全部保存在用户选择的 `<StoryForgeData>`，不再强制位于 C 盘或程序目录。

## 旧版迁移兼容

从任意 `0.x` 旧版迁移时，先等待任务结束并完全退出旧桌面端与 Worker，再把 `v1.0.5` 完整包解压到新的纯英文目录；首次启动会迁移可识别的长期数据，完成一条真实任务并由管理员确认后，才可清理旧目录。

## 日常制作

1. 选择小说、平台、口令、发布账号和要合并的分集。
2. 选择生产方案；需要时调整女声、语速、音乐、字幕、简介卡、口令卡与封面结尾。简介卡和口令卡可分别开关，并可填写它们在视频中的开始时间和显示时长；口令卡时长填 `0` 表示显示到视频结尾。
3. 选择“常规视频生成”“仅生成配音”或“已有配音更换素材”。仅生成配音每批只输出一份 MP3；换素材应选择 StoryForge 输出且带内嵌字幕索引的 MP3。
   - 常规视频生成：只交付 MP4，不再额外生成一份配音 MP3。
   - 仅生成配音：只交付 MP3。
   - 已有配音更换素材：只交付新 MP4。
4. 提交批次后可立即配置下一批，队列会按顺序制作；无需等待上一批结束。
5. 一个批次在任务胶片带中显示为一张可折叠卡；结束后可整批归档。

## 员工可用设置

- “制作默认值”用于预览、调整并保存自己的字幕、简介卡、口令卡和封面结尾方案，不会覆盖团队默认。
- “本机维护与软件更新”用于检查当前电脑的 FFmpeg、H.264 编码器、Kokoro、Edge TTS，并更新当前这台电脑。
- 制作台默认使用管理员维护的团队默认；员工可覆盖本批参数，并保存、修改或删除自己创建的个人方案。旧版内置/共享方案不再显示。
- “平台搜索文案”和“结尾引导文案”可在制作台按批次编辑。这里的内容只覆盖当前批次并随任务冻结，不会修改团队平台模板；团队模板仍由管理员维护，员工不会因此获得平台管理权限。
- 历史草稿或作业没有新的卡片开关/时间字段时会使用兼容默认值继续读取和执行，不需要重新保存，也不会被新批次的修改反向改写。

## 更新、日志与故障

- 核心程序会自动检查并在空闲时下载到 `<StoryForgeData>\updates`，经安全重启安装；不会覆盖数据目录。语言组件包使用独立的兼容性/SHA-256 校验、安全解压、原子切换和上一版回退流程，安装到 `<StoryForgeData>\components`。当前日语仍由完整包内置，无需员工另装。
- Hub 固定资料由主电脑备份，保留 72 小时且最多 3 份，相同内容按摘要去重；不会把员工视频素材、最终 MP4/MP3 或渲染缓存上传进备份。
- 启动与运行日志：`<StoryForgeData>\logs`。
- 单任务错误：`<StoryForgeData>\render-work\<批次>\<任务>\job-error.log` 或 `render-error.log`。
- 网页能打开但不能试听或生成时，先重新打开一次 `StoryForge Studio.exe` 并登录，再刷新网页。
- 仍有问题时双击 `admin-tools\diagnose_storyforge.cmd`，把诊断结果和对应任务日志交给管理员。`enable_storyforge_worker.cmd` 只供管理员维修，不属于首次使用流程。

## 清理或卸载

先退出 StoryForge 和本机制作服务。删除程序目录只移除程序；是否同时删除用户选择的 `<StoryForgeData>` 必须由员工明确决定。视频素材、音乐和最终输出目录不会被程序卸载自动删除。
