# StoryForge 员工电脑快速开始

适用源码版本：`0.4.0-rc7`

## 第一次使用

1. 把整个 `StoryForge Studio` 文件夹复制到本机短路径，例如 `C:\StoryForge`。不要只复制 EXE，也不要放进层级很深的目录。
2. 双击 `StoryForge Studio.exe`，只输入管理员创建的员工账号和密码。新员工默认密码为 `xs123456`。
3. 登录成功后，软件自动读取 Windows 电脑名称、连接预置的 Hub、登记当前电脑并启用后台制作服务；员工无需填写 Hub 地址、电脑名称或运行脚本。
4. 此后既可继续使用桌面程序，也可在本机浏览器打开管理员提供的团队网址；两端使用同一套制作功能。完整桌面窗口可以关闭。
5. 在制作台选择这台电脑自己的视频素材、背景音乐和输出文件夹；这些路径不会由管理员主机代填，也不会上传 Hub。
6. 左侧“设置”始终对员工开放：可维护“制作默认值”和“本机维护与软件更新”。小说、平台、口令、成员账号和 Hub 管理仍只对管理员开放。

## 日常制作

1. 选择小说、平台、口令、发布账号和要合并的分集。
2. 选择生产方案；需要时调整女声、语速、音乐、字幕、开头与封面结尾。
3. 可选择“常规视频生成”“仅生成配音”或“已有配音更换素材”。仅生成配音每批只输出一份 MP3；换素材应选择 StoryForge 输出且带内嵌字幕索引的 MP3。
4. 提交批次后可立即配置下一批，队列会按顺序制作。
5. 一个批次在任务胶片带中显示为一张卡；结束后使用“归档整批”。

## 员工设置

- “制作默认值”用于预览、调整并保存自己的字幕、简介卡、搜索口令和封面结尾方案，不会覆盖团队默认。
- “本机维护与软件更新”用于检查当前电脑的 FFmpeg、H.264 编码器、Kokoro、Edge TTS，并更新当前这台电脑。
- 一键制作方案分为“团队内置、团队共享、我的方案”：员工可套用前两类并覆盖本批参数，只能修改或删除自己创建的方案；团队默认由管理员维护。

## 输出与故障

- 默认每条只交付最终 `.mp4` 和同名纯旁白 `.mp3`；日志、字幕和缓存不会混进发布文件夹。
- 网页能打开但不能试听或生成时，先重新打开一次 `StoryForge Studio.exe` 并登录，再刷新网页。`admin-tools\enable_storyforge_worker.cmd` 只作为管理员维修工具，不属于员工首次使用流程。
- 仍有问题时双击 `admin-tools\diagnose_storyforge.cmd`，把生成的诊断结果交给管理员。
- 不要把员工电脑的素材或成片放在 Hub 主机目录；素材、渲染和成片始终由当前制作电脑负责。
