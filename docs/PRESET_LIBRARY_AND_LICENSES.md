# StoryForge 预设库、来源与许可说明

## 结论

StoryForge 的字幕、简介卡、口令卡、封面运镜和画面色调均由项目自身参数化实现。当前发布内容不包含、也不会从剪映/CapCut 安装目录、缓存、破解版程序或工程包中提取并重新分发专有素材。

“剪映风格”在本项目中只表示对通用视觉规律的原创实现，例如淡入上浮、遮罩揭示、柔和缩放、Ken Burns 运镜、逐词变色、暖色调和冷色调。实现使用 ASS/libass、FFmpeg 内建滤镜以及浏览器 CSS 动画，预览和成片通过同一预设 ID 对齐。

## 当前内置预设

- 简介卡：10 套外观、6 套入场动画。
- 字幕：13 套外观、6 套入场/同步方式。
- 口令卡：8 套外观。
- 封面结尾：12 套静态或运镜方式。
- 画面色调：6 套。
- 一键生产方案：至少 8 套，覆盖悬疑、浪漫、悲伤、复仇爽文、通用阅读、快速渲染、第一人称对白和逐词变色钩子。

所有预设在应用后都可继续修改；内置生产方案可保存覆盖，删除覆盖后恢复项目默认值。完整生产方案由 Hub 统一共享，带 `revision / content_hash / updated_by / updated_at`，因此多台制作电脑看到同一套方案并可追溯修改。方案只保存可迁移的创意与输出配置；小说、平台、口令、分集、发布账号、实际 Voice ID、本机视频/音乐/输出目录、封面路径、API Key、密码、Hub 凭据、命令和 FFmpeg 路径都不会被方案保存或覆盖。草稿与任务会冻结套用时的方案版本、哈希及完整解析配置，后续修改团队方案不会改变已排队任务。

## 实现边界

| 能力 | 预览 | 成片 | 技术 |
| --- | --- | --- | --- |
| 字幕样式与逐词变色 | 浏览器即时预览 | ASS/libass | CSS + ASS |
| 简介卡入场 | 浏览器即时预览 | ASS/libass | CSS + ASS 相对时间标签 |
| 封面全屏结尾 | 浏览器即时预览 | FFmpeg | CSS + FFmpeg filter graph |
| 画面色调 | 浏览器近似预览 | FFmpeg | CSS filter + FFmpeg 内建滤镜 |
| 卡片外观 | 浏览器即时预览 | ASS/libass | CSS + ASS |

浏览器对画面色调的显示是快速近似；最终颜色以 FFmpeg 输出为准。所有动画都必须是可定位（seek-safe）的，不能依赖只在页面连续播放时才正确的临时状态。

## 允许引入的第三方资源

如后续增加外部字体、图标或动画文件，必须同时满足：

1. 许可证明确允许复制、修改和随软件分发；
2. 固定版本或 Commit，不跟随不稳定的主分支；
3. 保存来源网址、版本、许可证文本、文件 SHA-256 和修改记录；
4. 不包含商标冒充、广告追踪、网络脚本、可执行代码或动态远程依赖；
5. 引入前完成离线扫描与渲染回归。

可优先评估 MIT/ISC/OFL 许可的项目，例如固定版本的 Magic CSS、旧版 Animate.css、Lucide、Inter 和 Noto 字体。FFmpeg 构建本身需单独核对 LGPL/GPL 配置。本文件不是第三方许可证替代品；实际打包时必须随包附带对应原文。

## 禁止引入的内容

- 从剪映/CapCut 或其他商业软件安装目录、缓存、工程包中提取的动画、贴纸、字体、模板或特效数据；
- 来源不明的“破解素材包”、网盘合集、去水印包；
- 没有明确再分发许可的 TikTok 视频、平台 Logo 合集、音乐和字体；
- 运行时从未知地址下载并执行的 JavaScript、Lottie 表达式、FFmpeg 命令片段或二进制文件。

平台 Logo 只能来自平台官方公开品牌资源、用户提供的合法素材，或由管理员自行上传；不得把小说封面中截取的未知 Logo 当成可通用分发的官方资源。
