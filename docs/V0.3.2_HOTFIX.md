# StoryForge Studio 0.3.2 热修复说明

发布日期：2026-07-27

## 修复目标

0.3.2 是面向多电脑生产环境的强制升级版本号。它确保已经安装过早期 0.3.1 构建的制作电脑，也能接收最终的 FFmpeg 路径转义修复。

## 核心修复

- 修复小说标题或输出目录包含英文单引号时，ASS 字幕路径在 FFmpeg `filter_complex` 中被提前截断的问题。
- 修复典型错误：`No option name near`、`Error parsing filterchain`、`Invalid argument`。
- 保留 0.3.1 的 15 秒样片、60 FPS、字幕预设、任务归档和网页生产能力。
- 更新包发布到 Hub 后，所有低于 0.3.2 的制作电脑均可识别为新版本，避免同版本旧构建被误判为“已经最新”。

## 制作电脑升级流程

1. 客户端连接 Hub 后自动检查并下载 0.3.2。
2. 在“设置 → 软件更新”确认安排重启安装。
3. 安全退出 StoryForge；更新 Worker 校验、替换并重新启动程序。
4. 返回制作台，仅重试失败的样片任务。

自动下载不会在视频渲染过程中强制关闭软件，避免破坏正在输出的成片。
