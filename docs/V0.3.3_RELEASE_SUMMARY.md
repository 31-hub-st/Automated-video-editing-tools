# StoryForge Studio 0.3.3 发布与交接摘要

发布日期：2026-07-27；源码维护验收：2026-07-28  
完整技术合同：[STORYFORGE_INTEGRATION_REPORT.md](STORYFORGE_INTEGRATION_REPORT.md)

## 本版最终生产流程

0.3.3 取消独立视频样片和审批门。制作台流程固定为：

1. 选择小说、平台、口令、发布账号和一个或多个分集；
2. 设置本批女声、语速、字幕、简介卡、口令卡、封面动效、素材、音乐和输出目录；
3. 用右侧 HTML/CSS 即时预览检查开头、正文字幕和封面结尾；
4. 点击“直接生成完整视频”，一次创建全部 `job_kind="full"`、`status="queued"` 任务并在制作电脑本机执行。

即时预览不生成 MP4、WAV、ASS 或生产记录，不占用 TTS 或 FFmpeg。接口仍为旧调用方返回 `preview_required=false` 和空 `preview_job_id`。历史 `preview` 状态只用于旧数据解码/迁移，通用失败重试会拒绝它，当前 UI、Hub 网页和制作电脑本地网页都不开放批准或重做入口。

## 多电脑最终架构

| 组件 | 负责内容 | 不负责内容 |
| --- | --- | --- |
| Hub 主电脑 | 小说、正文版本、简介、封面、平台、Logo、口令、发布账号、成员、权限、草稿、任务元数据、租约、生产记录、文本 AI、软件更新 | 不替其他电脑执行 TTS、字幕、素材编排或 FFmpeg |
| Hub 团队网页 | 共享资料与管理、受控上传、即时预览、记录和产物查看；在制作电脑上通过 loopback 执行器发起本机生产 | Hub 主机进程不替其他电脑执行候选配音、媒体建队、队列控制或渲染 |
| 制作电脑运行时 | 本机 TTS、候选女声、素材、音乐、字幕、队列、FFmpeg、输出和失败重试 | 不保存独立的权威小说库 |
| 制作电脑本地网页 | 在 `127.0.0.1` 上操作当前电脑的完整制作能力，同时读取 Hub 共享目录和文本 AI | 不能被局域网其他电脑直接访问，也不开放历史 preview 方法 |

首次连接只需主电脑地址、成员账号、密码和电脑名称。Hub 根据稳定安装 ID 自动登记设备并签发后台凭据；操作员不再生成、复制或保管令牌。旧令牌入口只保留在高级兼容区。

管理员可以查看、改名、停用任意数量的制作电脑，并向单台、多台或全部设备下发安全制作默认值。可下发内容只包含字幕、样式、语速、音乐比例、帧率等便携配置，不包含模型密钥、本机目录、编码器、Provider 地址或设备身份。

## 网页安全边界

- Hub 网页使用账号会话、HttpOnly/SameSite Cookie、CSRF、权限和所有权校验。
- 制作电脑本地网页仅监听 loopback，并校验 Host/Origin，防止 DNS rebinding 和跨站调用。
- 每个 client-local RPC 都重新向 Hub 校验账号、设备、设备凭据和当前有效权限；停用后立即失效。
- Hub 页面在制作电脑上经短时票据调用 `127.0.0.1:18765–18770`；client-local 页面直接调用同进程本地 API。生产白名单包含候选配音、免费 TTS 切换、目录、完整建队、队列、取消/重试、归档分页和打开输出，历史 preview 方法仍不开放。
- 本机素材和输出目录必须位于该电脑的默认工作目录或安全根目录；跨电脑草稿/归档里的绝对路径不会直接继承。

## 画面和音频结果

- 默认 H.264、1080×1920、60 FPS；可选 30 FPS 兼容模式。
- 顶部搜索口令卡全程保持稳定，字幕和口令遵守 TikTok 安全区。
- 支持整句/语义短语字幕，以及随旁白逐词弹出和变色的 `word_pop_sync`。
- 结尾 5–7 秒使用真实小说封面铺满 9:16，可选淡入、轻推近、轻拉远、慢速平移或柔和视差；不再显示白色平台结尾卡。
- CTA 继续由当前女声朗读，并使用当前正文字幕样式同步显示。
- 素材原声始终移除；音乐通过 ducking 避让旁白；素材不足时允许受控循环、镜像、裁切、起点变化和轻微变速。
