# StoryForge Studio 0.4.6 稳定版交付说明

发布日期：2026-08-01

## 本版目标

0.4.6 以员工制作电脑稳定生产为第一目标，同时完成多语言配音组件、简化制作流程、可管理预设、权威 Hub 备份恢复、设备清理和团队自动更新。

## 主要结果

- 常规视频生成只输出可直接发布的 MP4；仅生成配音输出 MP3；已有配音更换素材输出新的 MP4。
- 员工自行选择本机视频素材、音乐和输出文件夹；主机只保存小说库、平台、口令、账号、方案、任务与成品记录。
- 视频素材不再按小说类型强制匹配。素材目录递归扫描，重复制作会在可用素材内优先制造组合差异。
- 制作页提供四段快速定位、缺项自动定位、吸顶实时预览、简介卡开关和时长、字幕/字体/逐词效果、语速试听与个人方案。
- 管理员可删除小说、口令、成员、设备和所有方案；员工只能管理自己的方案。
- 本地 Kokoro 改为组件化发现与校验，日语等语言包可独立更新，不必每次重打整个主程序。
- Hub 恢复采用权威替换：小说、平台绑定、全部口令和相关固定资料按备份完整替换，不与旧库混合；恢复前自动留一份快照。
- 主程序仍使用完整 ZIP 原子更新，保留 SHA-256 校验、安装前验证、失败回滚和渲染中不强制重启。

- 全量自动测试：880 项；878 通过、2 跳过、0 失败、0 错误。

- 日语 Kokoro 语言组件：ready，issues 为空。
- 311.05 秒、1080×1920、30 FPS、封面结尾开启：真实渲染通过。
- 600 秒、1080×1920、60 FPS、封面结尾关闭：真实渲染通过。
- 两个视频均为 H.264，包含音轨；常规模式只输出一个 MP4，没有额外 MP3。
- 正式包内 7,836 个文件逐项核对，无缺失、无多余、无运行数据库、无员工素材、无测试音视频。

- 完整程序目录：`D:\StoryForgeRelease\0.4.6\dist\StoryForge Studio`
- 员工安装/更新包：`D:\StoryForgeRelease\0.4.6\artifacts\StoryForge-0.4.6-Windows-x64-update.zip`
- ZIP 大小：776,639,586 字节
- ZIP SHA-256：`156dde0b14c0b00de958b60f3faff24972ee20adb8795681ee2255bfe5dd998c`
- 程序入口：`StoryForge Studio.exe`

同一个 ZIP 既可用于新电脑完整安装，也可由 Hub 发布给现有员工电脑自动更新。包内没有 `StoryForgeData`，不会覆盖小说库、账号、任务记录或员工本机文件夹。

## 更新规则

1. 主机管理员只发布一次 0.4.6 完整 ZIP。
2. 已连接员工电脑按设置周期检查并在空闲时下载。
3. 正在渲染时不会安装；下载完成后，下次重启 StoryForge 自动应用。
4. 核心程序更新失败会回滚；配音语言组件独立下载、校验和切换。
5. 主机升级前保留 0.4.5 目录，待 0.4.6 主机和员工端通过实际验证后再删除旧版。

## 数据边界

- Hub：小说库、平台、口令、成员、设备、制作方案、任务与生产记录、备份、已发布更新。
- 员工电脑：视频素材、音乐、最终 MP4/MP3、临时渲染文件和本地 TTS/FFmpeg 运行环境。
- 最终成品只留在实际制作电脑；Hub 保存可查询记录，不集中承受视频渲染与文件存储压力。
