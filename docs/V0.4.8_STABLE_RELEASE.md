## 本次修复

- 使用高于 `0.4.7` 的正式版本号，确保已安装旧版的员工电脑能够发现、下载并安装更新。
- 修复 Windows 新启动后首次 TTS 缓存维护可能被错误跳过的问题。
- 统一 Windows 8.3 短路径与规范长路径的媒体目录身份，避免正确分类的视频或音乐被误判为不可用。
- GitHub Windows 门禁使用统一临时目录，避免托管运行器的短路径别名造成假失败。
- 修复本地网页队列测试中的竞争条件；生产环境“执行中的任务不能重试”保护保持不变。
- 保留 0.4.7 已验收的单重型任务、资源限流、磁盘治理、任务租约、原子发布、更新回滚与硬取消机制。
