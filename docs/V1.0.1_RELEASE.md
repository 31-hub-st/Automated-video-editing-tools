# StoryForge Studio v1.0.1 正式版交付报告

发布日期：2026-08-11

本版本基于正式版 v1.0.0 增量升级，保持既有视频生产顺序、队列、权限、数据结构与成品发布行为不变，重点补强故障诊断、Hub/制作端滚动升级兼容和前端静态资源交付完整性。

## 本次改进

- 为文本、配音、字幕、素材预检、渲染、质量检查和发布阶段增加只写诊断检查点；检查点不会被读取来跳过生产步骤，写入失败也不会令任务失败。
- 文案准备缓存改为原子写入，降低断电或强制退出留下半个 JSON 文件的风险。
- Hub 公布 RPC 契约、可用方法和设备能力字段；新制作端会按 Hub 实际能力投影请求，旧 Hub 仍按原四字段兼容。
- 女声候选的 `selection_key` 支持严格保存、读取与旧数据兼容，解决候选配音跨端持久化时的字段验证错误。
- 新主题样式作为正式静态资源纳入网页、Worker、启动自检和打包冒烟，防止正式包漏带样式文件。

## 数据保护与发布范围

- 更新 ZIP 明确不包含 `StoryForgeData`、SQLite/DB、Hub 备份、小说、平台、口令、账号、生产记录、渲染工作目录或成品视频。

- 本次仅发布到私有 GitHub 仓库，员工制作端不自动更新；管理员确认后再手动分发。
