# StoryForge Studio v1.0.2 正式版交付报告

发布日期：2026-08-12

本版本在 v1.0.1 基础上增加简介卡、口令卡的独立时间轴控制和员工单批平台文案覆盖，并收紧 Hub、员工便携版、本机制作服务与恢复流程之间的运行边界。正式更新包只包含程序，不包含任何业务数据库或 Hub 快照。

## 本次交付

- 简介卡和口令卡各自提供启用开关、以成片 `0` 秒为基准的绝对开始时间及显示时长；口令卡时长为 `0` 时持续到视频结尾。
- 员工可以编辑当前批次的平台搜索文案和结尾引导文案。覆盖内容随批次与作业冻结，不修改管理员维护的团队平台模板，也不授予 `platforms.manage`。
- 正式渲染、即时预览、字幕、封面和成片 manifest 使用同一时间窗口；超过成片长度的窗口会在视频结尾裁剪。
- 旧草稿和旧冻结作业缺少新字段时按旧模板语义读取，不继承当前电脑后来修改的卡片设置，也不回写旧数据。
- “已有配音更换素材”遇到新的自定义结尾文案时会在渲染前明确拒绝，要求重新生成旁白，避免音频、字幕和最终文案不一致。
- 冻结程序只有在受管启动器同时声明 Hub 角色和固定 DataRoot 时才可作为 Hub；员工便携版不会迁移旧 Hub 角色、凭据或业务库。
- Hub 网页进程不再占用本机制作 Worker、生产互斥锁或恢复渲染队列；Hub 桌面入口也不会把任意命令行参数带入正式数据根。
- 仓库根目录新增 `一键恢复StoryForge-Hub.cmd`。普通用户在新替换主机下载仓库 ZIP 后双击即可完成 UAC、GitHub CLI、浏览器认证、私库权限检查、正式包与 `hub-state-latest` 快照校验、恢复和部署验证。

## 数据保护与部署范围

- 更新 ZIP 不包含 `StoryForgeData`、SQLite/DB、`.sfbak`、小说正文、平台、口令、成员、设备、生产记录、API Key、素材、缓存、渲染工作目录或成品音视频。
- 本次测试、构建和独立解压冒烟全部使用隔离目录；没有启动、停止、替换或部署当前生产 Hub，也没有读取后写入、合并、清理或迁移任何 live SQLite。
- 当前 27 本正式业务库不是本 Release 的组成部分。新主机恢复必须通过一键入口另行下载并校验 `hub-state-latest`，仅下载最新程序不能恢复业务数据。
- Windows DPAPI 保护的 API Key 无法跨电脑迁移，换机恢复后必须由管理员重新填写。
- GitHub Release 发布不等于向员工端自动下发。是否在 Hub 内发布更新清单，仍由管理员在员工停工并完成真机冒烟后另行决定。
