## v1.0.2 承接说明

`v1.0.2` 的 GitHub Release 已标记为预发布“暂缓分发”。本报告核验时，其 ZIP 和同名 manifest 两项附件的 GitHub 下载计数均为 `0`。`v1.0.3` 承接 `v1.0.2` 已完成本地验收的业务能力，并以重新构建、重新验证的新版本交付，不移动或覆盖 `v1.0.2` 标签与附件。

承接的主要能力包括：

- 简介卡和口令卡各自拥有启用开关、以成片 `0` 秒为基准的绝对开始时间和显示时长；口令卡时长为 `0` 时持续到视频结尾。
- 员工可编辑当前批次的平台搜索文案与结尾引导文案；覆盖内容随批次和作业冻结，不修改管理员维护的团队模板，也不授予 `platforms.manage`。
- 正式渲染、即时预览、字幕与成片 manifest 使用同一时间窗口，旧草稿和旧冻结作业继续按兼容语义读取。
- 冻结 Hub、员工便携版、本机制作服务和恢复入口保持严格运行边界；仓库根目录继续提供 `一键恢复StoryForge-Hub.cmd`。

`v1.0.3` 在此基础上增加两项稳定性修复：

- Hub 接收上传失败时先完成 `.upload` 临时文件清理再返回错误；Windows 文件占用采用有界重试，最终失败会写入 Hub 错误状态。
- Windows 契约测试固定使用 Windows PowerShell 5.1，隔离不兼容的 `PSModulePath`，并把 8.3 短路径测试目录规范化为长路径，避免 GitHub Windows runner 环境差异造成误报。
