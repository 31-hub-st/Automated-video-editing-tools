## 历史操作入口（已停用）

不要再下载或运行 `StoryForge-1.0.4-update.zip`。普通用户只能在 `v1.0.5` 发布交付报告全部阻断项完成并成为正式稳定 Release 后，下载 `StoryForge-1.0.5-update.zip`，完整解压，再双击根目录的一键入口。

`v1.0.4` 当时设计的操作流程仅作为历史记录保留：

1. 用浏览器登录有私有仓库权限的 GitHub 账号。
2. 从当时的 Release 下载 `StoryForge-1.0.4-update.zip`，不要下载 Source code/源码 ZIP。
3. 完整解压 ZIP。
4. 双击解压目录根部的：

```text
一键恢复StoryForge-Hub.cmd
```

随后只需按中文提示完成浏览器授权并等待“恢复成功”。入口会自动申请管理员权限、检测或安装 GitHub CLI、验证私有仓库权限、下载并校验 `hub-state-latest`，完成后运行正式部署验证并打开 Hub 网页。若希望员工电脑无需改地址，新主机应继续使用原固定 IP `10.0.0.225`；恢复后还需重新填写不能迁移的 API Key。

该入口仅用于全新替换主机；已有 Hub 数据、任务、端口或正式进程的电脑会被安全拒绝。详细边界见 [StoryForge Hub 新电脑一键恢复](ONE_CLICK_HUB_RECOVERY.md)。
