## 本次修正目标

- 旧 Hub 启动器修复必须按 Windows SID 判断计划任务是否属于当前用户，兼容 Task Scheduler 返回的短用户名、`域\用户名` 或 SID；外来 SID、空主体和无法解析的账号仍须安全拒绝。
- 正式 `StoryForge-1.0.5-update.zip` 根目录必须直接包含 `一键恢复StoryForge-Hub.cmd`、`Restore-StoryForge-Hub.cmd` 和它们复用的恢复、部署与验证脚本。
- 保留 Hub 大库的轻量身份探针、非阻塞网页健康检查和备份 `ready` / `operational` 验证，不放宽 Release digest、manifest、快照或部署校验链。
- 保留简介卡与口令卡的独立开关、绝对开始时间和显示时长，以及员工对当前批次平台搜索文案和结尾引导文案的编辑权限。
- 不执行 Hub 恢复，不替换、合并、迁移、清理或手工修改 live SQLite；数据库、`.sfbak`、密钥、员工素材和成品不得进入 Git 或程序 Release。
