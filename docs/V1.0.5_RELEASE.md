# StoryForge Studio v1.0.5 历史暂缓发布报告

> **历史状态：停止分发。** `v1.0.5` 曾完成测试、冻结构建、包体审计与 GitHub 远程门禁，但正式换机验收随后发现 Windows PowerShell 5.1 部署验证输出不可靠。该 Release 已转为 **prerelease**、不是 GitHub `latest`，两个附件下载数均为 **0**。不得下载、部署或向员工分发本版本；唯一当前候选是 `v1.0.6`。

## 暂缓原因

`scripts/verify_storyforge_deployment.ps1` 使用 `@($checks)` 包装 `System.Collections.Generic.List[object]`。Windows PowerShell 5.1 在成功或失败验证路径上可能抛出 `Argument types do not match`，导致脚本无法输出 bootstrap 和一键恢复入口所依赖的最终 JSON。即使程序主体与其他门禁均通过，也不能把无法可靠完成部署验收的包作为正式换机交付。

`v1.0.6` 将在 `ConvertTo-Json` 前显式调用 `ToArray()`，并以 Windows PowerShell 5.1 的成功、失败两条真实子进程测试作为发布阻断项。
