## 本次修正目标

- Windows PowerShell 5.1 部署验收必须在成功与失败路径都输出可解析 JSON；`checks` 必须是 JSON 数组，不得再出现 `Argument types do not match`。
- 正式 `StoryForge-1.0.6-update.zip` 根目录必须直接包含 `一键恢复StoryForge-Hub.cmd`、`Restore-StoryForge-Hub.cmd` 和它们复用的恢复、部署与验证脚本。
- 保留旧 Hub 任务主体 SID 规范化、正式旧任务参数迁移、Hub 大库轻量身份探针、非阻塞网页健康检查和备份 `ready` / `operational` 验证，不放宽 Release digest、manifest、快照或部署校验链。
- 保留简介卡与口令卡的独立开关、绝对开始时间和显示时长，以及员工对当前批次平台搜索文案和结尾引导文案的编辑权限。
- 不执行 Hub 恢复，不替换、合并、迁移、清理或手工修改 live SQLite；数据库、`.sfbak`、密钥、员工素材和成品不得进入 Git 或程序 Release。
