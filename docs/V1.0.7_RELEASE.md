# StoryForge Studio v1.0.7 本地候选交付报告

> **状态：本地候选已完成验证，尚未发布。** 当前正式稳定基线仍为 `v1.0.6`。本报告是制品完成后的 docs-only 记录；它不改变、不重建也不替换制品源码提交 `8a67dd34cd055e5dbae6397dc4d0050676c81eb9`。尚未推送、创建 `v1.0.7` 标签或部署生产 Hub。

## 本版本范围

- 完整真实女声音色目录、单音色按需试听、搜索/风格筛选/收藏/个人隐藏/团队停用。
- 独立语速试听 RPC、缓存、连续切换 latest-request-wins 与准确错误分类。
- 简介卡/口令卡按正文秒数或正文百分比开始，按秒数/正文百分比/正文结束显示，并按真实正文配音时长冻结实际区间。
- 平台、口令和模板由小说库及服务端权威核对；员工可自由编辑不含权威 token 的结尾普通前后文。
- 新制作合同阻止旧 Worker 误领使用新语义的任务，同时保留旧草稿、旧候选和旧冻结任务执行兼容。
