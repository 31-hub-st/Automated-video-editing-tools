# StoryForge Studio v1.0.7 发布交付报告

> 状态：源码候选，尚未发布。当前正式基线仍为 `v1.0.6`。下面所有阻断证据必须来自最终提交的全量测试和隔离制品，不能复制历史版本数字。

## 本版本范围

- 完整真实女声音色目录、单音色按需试听、搜索/风格筛选/收藏/个人隐藏/团队停用。
- 独立语速试听 RPC、缓存、连续切换 latest-request-wins 与准确错误分类。
- 简介卡/口令卡按正文秒数或正文百分比开始，按秒数/正文百分比/正文结束显示，并按真实正文配音时长冻结实际区间。
- 平台、口令和模板由小说库及服务端权威核对；员工只能编辑不含权威 token 的结尾前后文。
- 新制作合同阻止旧 Worker 误领使用新语义的任务，同时保留旧草稿、旧候选和旧冻结任务执行兼容。
