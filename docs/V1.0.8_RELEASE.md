# StoryForge Studio v1.0.8 发布交付报告

> **状态：候选开发中，禁止发布。** 版本源已准备为 `1.0.8`，但源码提交、完整测试、冻结构建、制品哈希、远程门禁、正式 Release 与生产部署证据仍为 TODO。任何 TODO 未由本版本真实结果替换前，不得把源码目录、旧 `v1.0.7` ZIP 或临时构建当作 `v1.0.8` 交付程序。

## 本版本范围

- 继承 `v1.0.7` 的完整真实音色目录、独立语速试听、混合卡片时间轴及旧数据兼容。
- 制作台允许员工自由编辑本批“平台口令卡文案”和“结尾引导文案”的完整模板；管理员平台模板作为默认值。
- `{platform}`、`{code}` 必须各保留一次且不能添加未知变量。服务端保存与排队时依据小说绑定和有效口令重新核对、替换真实值，并冻结本批模板与最终解析结果。
- schema 2 草稿中的 `platform_ending_prefix/platform_ending_suffix` 兼容合并为完整结尾模板；已冻结旧任务保持历史结果不变。
- Kokoro 可用性单测通过明确夹具隔离开发机/CI 组件状态；生产音色可用性仍保持缺组件即不可用的 fail-closed 合同。
